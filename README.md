# 科學記數法 · 互動教學頁

以「小數點移位」為核心的互動教學網頁，內容依據 **03_2B08 整數指數律** 工作紙（科學記數法部分）編寫，適合中二至中三學生自學或課堂示範。

線上版：<https://tyhcch1234.github.io/scientific-notation/>

## 內容結構

| 部分 | 內容 |
| --- | --- |
| 0 概念 | `a × 10ⁿ`（1 ≤ \|a\| < 10）的定義、左右移位與指數增減的關係、10 的次方對照表 |
| 1 例題一 | 大於 10 的數：700、56 800、−23 |
| 2 練習一 | 4000、500 000、−8500 |
| 3 例題二 | 小於 1 的數：0.8、0.045、−0.002 |
| 4 練習二 | 0.01、0.005、0.000 45、0.000 002 47、−0.000 009、−0.0035 |
| 5 例題三 | 還原：2 × 10³、6 × 10⁻² |
| 6 練習三 | 7 × 10⁶、8.14 × 10⁵、4 × 10⁻³、1.2 × 10⁻⁴ |
| 7 自我測驗 | 8 題隨機出題（大數／小數／還原，含負數），即時評分 |
| 8 常見錯誤 | 四個最常扣分的地方與一分鐘自我檢查 |

## 互動設計

- **小數點移位器**：逐步／自動示範把小數點移到位，同步顯示 `× 10ⁿ` 的變化，並即時判斷是否已達標準形式。
- **三組練習即時批改**：分開填「前面的數 a」與「指數 n」，錯誤訊息會針對常見問題（a 不在 1–10、指數方向錯、漏負號）給提示；可顯示逐步題解。
- **自我測驗**：每次重新洗牌出題，答對才可進入下一題，最後給總分與程度評語。
- 純靜態單一 HTML 檔，無外部依賴，可離線使用；支援手機與桌面；尊重 `prefers-reduced-motion`。

## 本機使用

直接用瀏覽器開啟 `index.html`，或：

```bash
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 備註

- 頁面內的例題與練習題目、題解數字均對應原工作紙內容；工作紙原檔的公式為嵌入物件，已在整理時逐一核對（例如 56 800 = 5.68 × 10⁴、−0.002 = −2 × 10⁻³）。
